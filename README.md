# Mini Fire

2D LAN multiplayer jetpack shooter (Godot 4.4.1). Currency: MFC (coins) and Gems.

- Persian proposal & roadmap: `docs/PROPOSAL_FA.md`
- Technical handoff / APK export / plugins: `docs/HANDOFF_FOR_CLAUDE.md`
- Smoke tests: `tests/run_tests.sh practice`

Controls (PC): A/D move, W or Space jetpack, mouse aim, left click fire, R reload, Q swap.
Touch: left stick move/fly, right stick aim+fire, R and SWAP buttons.
