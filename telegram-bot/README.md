# بات فروش جم تلگرام

باتی که در کانال/چت تلگرام شما کد جم تولید می‌کند و کاربر کد را داخل بازی (اسپین شاپ ← ثبت کد جم) وارد می‌کند. کدها با همان الگوریتم HMAC بازی ساخته می‌شوند و فقط یک‌بار قابل استفاده‌اند.

## راه‌اندازی

1. در تلگرام به [@BotFather](https://t.me/BotFather) پیام دهید: `/newbot` → توکن بات را بگیرید
2. توکن را در متغیر محیطی بگذارید:

```bash
BOT_TOKEN=123456:ABC-DEF... ADMIN_ID=آیدی_عدی_خودتان node bot.js
```

- `ADMIN_ID` (اختیاری): اگر بگذارید فقط شما می‌توانید کد صادر کنید. برای دیدن آیدی عددی خودتان، به بات `/id` بدهید.
- اگر 0 بماند، هرکسی که بات را باز کند می‌تواند کد بگیرد — برای فروش عمومی مناسب نیست.

3. بات را به کانال فروشتان ادمین کنید یا لینکش را در پین کانال بگذارید

## استفاده

خریدار به بات `/start` می‌زند و `/id` را برایتان می‌فرستد. شما بعد از دریافت پرداخت:

```
/issue 500 123456789
```

بات کد می‌سازد:

```
MF-A83K2P-XR7TQ-500
```

و شما آن را برای خریدار می‌فرستید. خریدار در بازی: **اسپین شاپ → ثبت کد جم**.

## نکات

- کد فقط یک‌بار قابل استفاده است (بازی کدهای استفاده‌شده را ثبت می‌کند)
- کد به تعداد جم وصل است، نه به اکانت؛ هر کسی که کد را داشته باشد می‌تواند استفاده کند — پس فقط به خریدار بدهید
- قیمت‌گذاری و پرداخت (کارت‌به‌کارت و…) خارج از بات است؛ بات فقط کد تولید می‌کند

## اجرای دائمی (اختیاری)

روی هر سرور کوچک (یا همین سیستم با pm2):

```bash
npm install -g pm2
BOT_TOKEN=... ADMIN_ID=... pm2 start bot.js --name minifire-gems
```
