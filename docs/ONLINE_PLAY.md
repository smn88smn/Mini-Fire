# بازی آنلاین (روم‌های ۱۶ نفره P2P)

## چطور کار می‌کند

- کسی که **روم می‌سازد = هاست** است؛ بازی روی گوشی او اجرا می‌شود و بقیه مستقیم به IP او وصل می‌شوند (P2P روی UDP، بدون سرور واسط)
- تا **۱۶ بازیکن** در هر روم
- هر بازیکن موقع ورود **رنگ** انتخاب می‌کند (۱۶ رنگ) — گروه‌های رنگی با هم می‌جنگند
- بعد از شروع بازی توسط هاست، همه هم‌زمان وارد مچ می‌شوند

## ورود به روم

### روش ۱: کشف خودکار (مثل یک وای‌فای)
اگر همه روی **یک وای‌فای/هات‌اسپات** باشید:
1. هاست: منوی Online → **Create Room**
2. بقیه: منوی Online → **Join Room** → روم هاست در لیست خودکار دیده می‌شود → انتخاب و Join

### روش ۲: IP دستی
اگر روم در لیست نیامد، هاست IP خودش را (بالای صفحه رومش نوشته شده) به بقیه بدهد؛ بقیه در قسمت Join عدد IP را وارد کنند.

## بهترین راه برای ایران

چون P2P مستقیم است و IP عمومی/خصوصی ایران معمولاً NAT پشت NAT است، بهترین گزینه‌ها به ترتیب:

1. **هات‌اسپات موبایل** (رایج‌ترین و ساده‌ترین): یکی هات‌اسپات باز کند، بقیه وصل شوند، روم با کشف خودکار پیدا می‌شود. برای دورهمی‌های حضوری عالی است.
2. **VPN مشترک با IP ثابت**: اگر همه یک VPN مشترک بگیرند که IP عمومی به هر نفر می‌دهد (مثل برخی VPN‌های گیمینگ)، IP هاست را دستی وارد کنید.
3. **وای‌فای خانه/محل کار**: مثل هات‌اسپات، کشف خودکار کار می‌کند.

نکته: روم‌ساز باید همیشه در روم بماند؛ اگر هاست بازی را ببندد، روم می‌پرد.

## چت/هماهنگی

داخل روم پیام‌گذاری سریع نیست؛ برای هماهنگی IP و زمان، از تلگرام استفاده کنید.

## تربون (آزمایش)

قبل از روم آنلاین، می‌توانید با **Practice with Bots** آفلاین با ربات‌ها تمرین کنید — همه مکانیک‌ها (اسلحه‌ها، لول‌ها، سوختن، پاورها) فعال است.
